# AI見積アシスタント（配送・設置案件向け）デモ

配送・設置・物流工事・産業廃棄物収集運搬の見積を、条件入力から自動算出するデモアプリです。
サンプルデータのみで動作し、サーバー・ビルド環境は不要です（静的HTML）。

## 画面構成

| 画面 | 内容 |
|---|---|
| ① 見積作成 | 11項目の条件を入力 → 金額・内訳・算出根拠を表示。営業担当者による調整スライダー付き |
| ② 見積書プレビュー | 見積書フォーマットへの流し込み（印刷・PDF出力可） |
| ③ 案件管理表 | 見積確定と同時に自動登録される案件一覧 |
| ④ 料金ロジック | タリフ・作業内容マスタ・補正係数・過去見積データを全公開 |
| ⑤ ばらつき分析 | 同一条件での担当者別ばらつきと、AI提示額との差分ログ |

## 料金算出の三層構造

1. **第1層：タリフ（確定ルール）** — 料金表がある条件は必ず同じ金額を再現
2. **第2層：過去実績AI（類似案件検索）** — タリフ外の条件のみ、過去見積から条件の近い案件を検索してkm単価の中央値で算出。参照した案件と類似度を画面に表示
3. **第3層：補正係数** — 前面道幅（搬入難度）・時期・パートナー企業の原価差を係数で反映

見積ごとに「第1層でカバーできた割合」を表示し、どこまでが確定ルールでどこからがAI推定かを明示します。

## ファイル構成

- `index.html` — 画面
- `data.js` — マスタ（拠点座標・タリフ・作業内容・補正係数・過去見積28件）
- `engine.js` — 距離算出／タリフ判定／類似案件検索／見積算出
- `app.js` — 画面制御・描画
- `style.css` — スタイル

## ご注意

本デモはサンプルデータによる動作例です。実在の企業・料金とは関係ありません。
