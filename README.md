# AI見積アシスタント（配送・設置案件向け）デモ

配送・設置・物流工事・産業廃棄物収集運搬の見積を、条件入力から自動算出するデモアプリです。
サンプルデータのみで動作し、サーバー・ビルド環境は不要です（静的HTML）。

## 画面構成

| 画面 | 内容 |
|---|---|
| ① 見積作成 | 荷物を品目×台数で入力 → 積載量・必要車両台数・必要作業人数・金額を算出 |
| ② 積載・人員の算出根拠 | STEP1〜4の途中計算をすべて開示（なぜこの台数・この人数なのか） |
| ③ 見積書プレビュー | 見積書フォーマットへの流し込み（印刷・PDF出力可） |
| ④ 案件管理表 | 見積確定と同時に自動登録される案件一覧 |
| ⑤ 料金ロジック | 品目マスタ・車両マスタ・作業係数・車両タリフを全公開 |
| ⑥ ばらつき分析 | 同一条件での担当者別ばらつき |

## 算出の流れ

1. **荷物明細 → 積載量** — 品目マスタ（荷姿の容積・重量）から総容積・総重量を集計
2. **積載量 → 必要車両台数** — 容積基準と重量基準の両方で台数を出し、大きい方を採用。前面道幅で入れる車格を制限し、運賃合計が最小の車格を選択。作業員の乗車人数も台数の制約に加える
3. **作業量 → 必要作業人数** — 設置人時（品目の標準時間 × 必要人数 × 台数）＋荷降ろし人時に、納品先条件・前面道幅の係数を掛けて必要人数を算出。2名作業が必要な品目があれば最低人数を確保
4. **金額** — 車両費（タリフ）＋作業費（人数×日数×時間×単価）＋付帯費＋補正係数

すべて決定的な計算で、生成AIは使っていません。同じ条件なら必ず同じ結果になります。
タリフ対象外のエリアのみ、距離あたり単価による実績ベースの推定となり、その割合を画面に表示します。

## ファイル構成

- `index.html` — 画面
- `data.js` — マスタ（品目16種・車両4車格・作業係数・タリフ・拠点座標・案件プリセット）
- `engine.js` — 荷量集計／車両構成の決定／必要作業人数の算出／金額計算
- `app.js` — 画面制御・描画
- `style.css` — スタイル

## ご注意

本デモはサンプルデータによる動作例です。実在の企業・料金とは関係ありません。
